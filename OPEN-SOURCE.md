# Componente open-source

- **Piper** — motor local neural text-to-speech: <https://github.com/OHF-Voice/piper1-gpl>
- **Piper Russian voice `ru_RU-denis-medium`** — model distribuit prin colecţia Piper Voices;
  verifică `MODEL_CARD` al modelului înainte de utilizarea comercială.
- **FFmpeg** — codificare MP4 H.264/AAC, animaţie şi subtitrări: <https://ffmpeg.org/>
- **Wrangler / Cloudflare Workers SDK** — publicarea Worker-ului: <https://github.com/cloudflare/workers-sdk>

Aceste componente nu sunt incluse ca binare în arhivă. Workflow-ul GitHub le instalează
din sursele lor oficiale în timpul randării. Fiecare componentă rămâne sub propria licenţă.
